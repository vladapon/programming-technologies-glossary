# Словник нових термінів з програмування
**Розділ:** Парадигми та технології програмування

| № | Термін | Визначення | Парадигма / Контекст |
| :--- | :--- | :--- | :--- |
| 1 | **Імперативне програмування** | Парадигма, в якій код описує послідовні команди для зміни стану програми (як саме досягти результату). | Базові парадигми |
| 2 | **Декларативне програмування** | Парадигма, де описується бажаний результат, а не послідовність кроків для його отримання (що потрібно отримати). | Базові парадигми |
| 3 | **ООП** | Об'єктно-орієнтоване програмування — парадигма, де головними елементами є класи та об'єкти. | ООП |
| 4 | **Інкапсуляція** | Приховування внутрішньої реалізації об'єкта від прямого доступу ззовні задля безпеки даних. | Концепції ООП |
| 5 | **Успадкування** | Механізм, що дозволяє одному класу переймати властивості та методи іншого (батьківського) класу. | Концепції ООП |
| 6 | **Поліморфізм** | Здатність об'єктів з різними типами обробляти виклики методів з однаковою назвою, але своєю логікою. | | Концепції ООП |
| 7 | **Функційне програмування** | Парадигма, яка розглядає процес обчислень як корисне обчислення математичних функцій і уникає змінних станів. | Альтернативні парадигми |
| 8 | **Компіляція** | Процес перекладу всього вихідного коду програми в машинний код перед її запуском. | Технології |
| 9 | **Інтерпретація** | Процес виконання коду програмою-інтерпретатором крок за кроком (построково) без попереднього збирання. | Технології |
| 10 | **API** | Інтерфейс прикладного програмування, який дозволяє різним програмам взаємодіяти та обмінюватися даними між собою. | Технології |
